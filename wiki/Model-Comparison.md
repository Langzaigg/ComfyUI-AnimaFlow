# 模型实测横评

现役工作流的同条件实测对比（同 seed、同场景，SFW + NSFW），用于按用途选模型。已移除的 miao / kira / nova、fuse1.0、rdbt、Aura 系列不再列入选型。

## 测试方法

- 同 seed、同提示词、同画幅；仅质量前缀按各模型规范写法
- 覆盖多人复杂场景、单角色还原、指定画师风格、常规 NSFW、高难度非常规构图 NSFW
- 测试脚本在 `examples/` 下，历史报告在 `examples/results/*/report.md`

## 结论速查

## 分场景表现

### 多人复杂场景

Silvermoon 的多角色外貌、动作和场景元素遵循最稳；anima29 的构图与细节突出但速度较慢。

### 单角色还原

知名角色在现役工作流中均能较好还原，Silvermoon 与 Anima 2.9B 系列较稳定。角色标志物、服装和复杂道具仍可能随 seed 出错。

### 指定画师风格

Fuse / Turbo 1.1 的质量词提示词体系与 Silvermoon 的 `score_N` 前缀对画师 tag 响应较好；Anima 2.9B 系列需显式使用 `@画师` 锚定画风。

### NSFW

- 常规姿势：现役各工作流都能正常出图。
- 假签名 / 乱码水印：turbo 系可写文字类 `neg` 并配 cfg 1.2；Fuse 与 Silvermoon 系走无负面，偶发时可用 reroll。
- 复杂解剖和非常规构图仍可能失败，不能保证提示词全部命中。

## 选型建议

- **日常快速出图**：`anima29_turbo` 或 `fuse`
- **最终成稿**：`anima29`
- **指令遵循 / 角色还原优先**：`silvermoon`
- **经典日系与 Aesthetic 画风**：`turbo_v1.1` / `aesthetic_v1.1`
- **写实照片风**：`ultrareal`；**写实插画**：`cyberreal`
- **MOSS Layout、漫画分格与字面文字**：使用独立的 `/moss/*` 工作流
