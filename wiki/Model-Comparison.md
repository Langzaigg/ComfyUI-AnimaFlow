# 模型实测横评

2026-08 对现役工作流做的同条件实测对比（同 seed 同场景，SFW + NSFW），结论用于指导按用途选模型。

> 历史说明：2026-08 上旬的旧横评覆盖 miao / kira / nova 等模型；这些工作流已于 2026-08-28 从项目移除（被 2.9 系全面超越），旧结论不再保留。

## 测试方法

- 同 seed、同提示词、同画幅；仅质量前缀按各模型规范写法
- 覆盖场景：多人复杂场景、单角色还原、指定画师风格、常规 NSFW、高难度非常规构图 NSFW
- 测试脚本在 `examples/` 下（`*_test.py`），逐场景报告在 `examples/results/*/report.md`，可复现

## 结论速查

## 分场景表现

### 多人复杂场景

silvermoon 指令遵循最稳（多角色外貌、动作、场景元素基本全中）；anima29 构图与细节最好但慢；anima29_rdbt 在 16 步档位细节保留最完整。

### 单角色还原

知名角色各现役工作流都能较好还原，silvermoon 与 anima29 系最稳定。

### 指定画师风格

fuse / turbo_v1（质量词有效的 turbo 提示词体系）与 silvermoon（score_N 前缀）对画师 tag 响应都好；anima29 系需显式 `@画师` 锚定画风；aura 写实路线（photo real / real skin）下**不要**带画师 tag（会真人化、丢失动画角色特征）。

### NSFW

- 常规姿势：现役各工作流都能正常出图
- 假签名 / 乱码水印：`fuse` 发作最少（内置文字类负面默认以 cfg 1.2 生效）；其余 turbo 系（turbo_v1 / anima29_turbo / anima29_rdbt）写文字类 `neg` 并配 cfg 1.2 可同等压制
- 马赛克 / 黑条：2.9B 系（anima29 / anima29_turbo / anima29_rdbt / fuse）全程零自发发作，无需在正面提示词写无码类标签

## 选型建议

- **日常均衡**：`anima29_rdbt`（质量/速度平衡最优）
- **最终成稿**：`anima29`（质量天花板）
- **快速迭代 / 实时出图**：`anima29_turbo` 或 `fuse`（8 步；fuse 伪影最少、质量词有效）
- **指令遵循 / 角色还原优先**：`silvermoon`
- **低显存**：`aura` / `aura-speed`（显存约为 BF16 一半，质量同档）
- **写实照片风**：`ultrareal`（三段式提示词）
